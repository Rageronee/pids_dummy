Software PIDS Selektor
Deskripsi Singkat
Software PIDS Selektor adalah aplikasi yang berfungsi untuk memilih dan mengirimkan data informasi kereta ke Software Windows Mini PC. Software ini menampilkan data ke display PIDS, melainkan bertindak sebagai sumber seleksi data PIDS.
Aktor
Operator PIDS: Petugas yang mengoperasikan software PIDS Selektor
Kebutuhan Fungsional

Kode
Deskripsi
PIDS-001
Sistem harus memungkinkan pemilihan Nama Kereta
PIDS-002
Sistem harus memungkinkan pemilihan Nomor Kereta
PIDS-003
Sistem harus menampilkan data dari sensor
PIDS-004
Sistem harus mengirim data PIDS ke Software Mini PC
PIDS-005
Sistem harus mencatat log pengiriman data
PIDS-006
Sistem harus menampilkan status koneksi ke Mini PC
PIDS-007
Sistem harum menyimpan log data sensor

Kebutuhan Non-Funsional

Kode
Deskripsi
Kategori
PIDS-NFRS-001
Waktu pengiriman data ≤ 3 detik
Performance
PIDS-NFRS-002
Sistem mudah digunakan oleh operator (sederhana)

Software Windows Mini PC
Deskripsi Singkat
Software Windows Mini PC adalah aplikasi utama yang berjalan di dalam gerbong kereta makan. Software ini digunakan oleh Operator Kereta Makan untuk monitoring real-time, pengelolaan data kereta, serta menampilkan informasi ke layar tv (screen) pada gerbong kereta penumpang.
Aktor
Operator: Pengguna utama untuk monitoring dan mengelola data kereta
Kebutuhan Fungsional
Akses

Kode
Deskripsi
MPC-001
Sistem hanya dapat diakses oleh Operator
MPC-002
Sistem harus otomatis berjalan saat Mini PC menyala

Integrasi Data Kereta

Kode
Deskripsi
MPC-003
Sistem harus memungkinkan untuk update data (lokal)
MPC-004
Sistem harus memungkinkan menerima dan mengirim data dari dan pada PIDS Selektor
MPC-005
Sistem harus memungkinkan menerima dan mengirim data dari dan pada Command Center
MPC-006
Sistem harus menyimpan data terakhir saat offline

PIDS

Kode
Deskripsi
MPC-007
Sistem harus menerima data dari PIDS Selektor
MPC-008
Operator dapat update Nama Kereta
MPC-009
Operator dapat update Nomor Kereta
MPC-010
Sistem harus menampilkan log PIDS (read-only)

GPS

Kode
Deskripsi
MPC-011
Sistem harus menampilkan peta lokasi kereta
MPC-012
Sistem harus menampilkan tracking per gerbong
MPC-013

CCTV

MPC-015

Software Command Center
Deskripsi Singkat
Software Command Center adalah sistem terpusat yang digunakan oleh Admin (Kontrol Pusat) untuk mengelola data kereta, operator, serta melakukan monitoring ke seluruhan armada kereta.
Aktor
Admin: monitoring dan kelola seluruh data armada kereta
Kebutuhan Fungsional
Manajemen User

Kode
Deskripsi
CTR-001
Admin harus dapat login dan logout pada sistem
CTR-002
Admin dapat mengelola data dan akses Operator

Manajemen Data

Kode
Deskripsi
CTR-003
Admin dapat melakukan CRUD pada seluruh data (data master)
CTR-004
Admin dapat memonitor status kereta

Monitoring Pusat

Kode
Deskripsi
CTR-005
Sistem menampilkan data GPS seluruh kereta
CTR-006
Sistem menampilkan status koneksi Mini PC

Integrasi Cloud

Kode
Deskripsi
CTR-007
Sistem harus mengelola sinkronisasi data ke Mini PC
CTR-008
Sistem harus menyimpan seluruh histori data

Kebutuhan Non-Funsional

Kode
Deskripsi
Kategori
CTR-NFRS-001
Sistem tersedia 24/7 (always on)
Reliability
CTR-NFRS-002
Sistem hanya bisa diakses oleh Admin
